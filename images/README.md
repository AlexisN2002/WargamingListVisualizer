# Your images go here

Make one folder per army, named like the faction line of your New Recruit
export (case and spaces don't matter):

```
images/
├── tyranids/
│   ├── army.json              (optional, copy example-army.json)
│   ├── dispositions.jpg       (optional disposition card) or dispositions/*.png
│   ├── hormagaunt-a.webp
│   ├── hormagaunt-b.webp
│   ├── tyranid-prime.webp
│   └── norn-emissary.webp
└── space-marines/
    └── ...
```

These files are ignored by git, so your images never end up in the repository.
See the main README for naming rules and options.
